# Bantu Trader Capital

Crie um site institucional completo de asset management/gestão de investimentos, com 4 páginas: Home, Products, About e Blog. Estilo: dark, premium, institucional, com tema preto e dourado.

=== IDENTIDADE VISUAL ===

- Fundo geral: preto profundo (#0A0A0A a #0D0D0D)

- Cards/seções: preto ligeiramente mais claro (#141414 / #161616) com bordas sutis (1px, cinza escuro translúcido) e cantos bem arredondados (16-24px)

- Cor de destaque (accent): dourado/âmbar (#C9A24D)

- Verde para indicadores positivos/baixo risco (#3DDC84 estilo)

- Vermelho/coral suave para alto risco

- Texto: branco (#FFFFFF) para títulos, cinza claro (#A3A3A3) para texto secundário

- Tipografia: sans-serif bold/geométrica para headlines (estilo Space Grotesk ou similar), sans-serif limpa para corpo (Inter)

- Nav flutuante: pill arredondado, fundo escuro semi-transparente com blur, fica fixo ao rolar

- Logo: ícone de pássaro/fênix estilizado em gradiente dourado + wordmark "[Nome]" (primeira parte branca, segunda parte em dourado) com subtítulo pequeno "Asset Management" embaixo

- Botões primários: fundo dourado sólido, texto preto, cantos arredondados (pill)

- Botões secundários: outline/transparente com borda sutil

- Widgets flutuantes no canto inferior direito: botão WhatsApp (verde) + botão de chat (dourado/marrom)

=== NAVEGAÇÃO (todas as páginas) ===

Logo à esquerda | Links centrais: Home, Products, About, Blog | Botão CTA à direita: "Book a Consultation" (com ícone de cadeado) na Home, "Contact" nas outras páginas
